# Api-game

Веб-приложение для просмотра каталога видеоигр. Данные загружаются из API,
игры отображаются карточками, а по клику открывается модальное окно с
подробной информацией.

## Демо

[Открыть сайт](https://pavel732007.github.io/Api-game/)

## Возможности

- Список игр в виде карточек (обложка, название, жанр, рейтинг, описание)
- Модальное окно с подробной информацией: разработчик, издатель, платформы,
  цена, системные требования, теги
- Закрытие окна по крестику, клику на фон и клавише Escape
- Адаптивная вёрстка (компьютер и телефон)

## Технологии

- TypeScript
- HTML5 / CSS3
- Fetch API

## Установка и запуск

1. Клонируйте репозиторий:

```bash
git clone https://github.com/pavel732007/Api-game.git
cd Api-game
```

2. Установите зависимости:

```bash
npm install
```

3. Запустите проект в режиме разработки:

```bash
npm run dev
```

4. Соберите проект для публикации:

```bash
npm run build
```
